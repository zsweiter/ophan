Ophan API Gateway

Ophan is a high-performance API Gateway written in Rust, designed to provide a secure, scalable, and low-latency entry point for modern APIs and microservices. It combines reverse proxy capabilities, intelligent routing, authentication, load balancing, caching, traffic management, and an integrated Web Application Firewall (WAF) into a single lightweight server.

Features

  • High-performance reverse proxy with minimal latency.
  • Flexible routing and request rewriting.
  • Load balancing with active health checks.
  • JWT, OAuth 2.0, OpenID Connect.
  • TLS termination with HTTP/1.1, HTTP/2 support.
  • Integrated Web Application Firewall (WAF).
  • Rate limiting, CORS, and security policies.
  • Static file serving and response caching.
  • Hot configuration reload without downtime.
  • Built for cloud-native and microservice environments.
